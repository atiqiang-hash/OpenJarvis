Serenity「卡点猎手」股市分析仪表盘  v1.2
============================================

【这是什么】
基于 X 账号 @aleabitoreddit（Serenity）公开市场分析方法论的可交互股市
分析仪表盘。核心思路：不追龙头，把超大厂 AI 资本开支沿供应链逆向拆解，
猎杀单点瓶颈（chokepoint），布局被错配的微/小市值标的。

【文件清单】
- index.html      仪表盘主程序，双击用浏览器打开即可（单文件，零安装）
- 使用教程.docx    完整图文使用说明（Word）
- README.txt      本快速说明

【怎么用】
1. 双击 index.html（推荐 Chrome / Edge / Safari）。
2. 打开后自动拉取 Finnhub 实时美股行情；顶部状态灯变绿 = 成功。
3. 标的看板可筛选/排序；评分器可自查选股；点击供应链层看详情。

【实时行情】
- 数据源：Finnhub 免费层（美股，60 calls/min），已内置免费 Key，开箱即用。
- 「↻ 刷新行情」手动刷新；「自动 60s」定时刷新；「🔑 API Key」可换成你自己的 Key
  （存在浏览器本地，不写回文件）。注册地址：https://finnhub.io/dashboard

【保存到移动 SSD】
解压 → 把「Serenity-卡点仪表盘」整个文件夹拖进 SSD → 以后双击 index.html 即可。
